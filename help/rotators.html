OscarWatch can point your antenna during a pass. Configure the rotator under Settings → Rotator. Serial controllers need a COM port different from the radio (on Linux prefer a stable by-id path — Linux serial ports). Network controllers (OZ9AAR URC) use a TCP host and port instead. Serial protocols (GS-232, EasyComm, SPID, SAEBRTrack) can also use a TCP serial connection (for example ser2net) instead of a local COM port.

Main settings

  • Connection — for serial protocols, choose Serial (COM port) or TCP serial (e.g. ser2net). Baud rate applies only to local serial; configure baud on the ser2net (or similar) server when using TCP.
  • Serial port and rotator type (when Connection is Serial). On Linux, see Linux serial ports for stable paths after reboot.
  • Green Heron RT-21 Az-El: plug in both USB cables. Choose this type (not GS-232). Set the azimuth and elevation COM ports separately. Default baud is 4800 (DCU-1). Default elevation range is 90°. Overlap (450°) only works if the RT-21 itself is set for overlap in the Green Heron setup utility. On Linux, prefer by-id paths so az/el do not swap after reboot.
  • TCP serial: enter host and TCP port for a raw serial tunnel. OscarWatch speaks the same protocol bytes as over COM (not URC JSON). Prefer a local network — high latency can cause timeouts.
  • OZ9AAR URC (TCP): enter the URC host (IP or hostname) and TCP port (default 1111). On the controller, enable the socket server and select REM / remote tracking mode. OscarWatch sends JSON POLL and GOTO requests; there is no separate stop command — Stop re-issues GOTO at the current position.
  • EasyComm II: set the controller to EC (or EasyComm) mode. Default baud is 9600 when you pick this type in Settings; use 1200 if your controller manual specifies it (some SPID emulation modes).
  • SAEBRTrack: select this type for PSR-100, Arduino SAEBRTrack sketches, and similar fire-and-forget rotors. Default baud is 9600. Commands are compact whole-degree AZnnnELnnn. There is no position feedback — OscarWatch does not send AZ/EL queries (those would be misread as move-to-zero on many controllers). The sidebar shows the last commanded az/el instead.
  • SPID native mode: set the controller to SP protocol and Auto (A) on the front panel before connecting.
  • Azimuth range — 360° or 450° (G-5500 style).
  • Smart azimuth (450°) — uses 361–450° for the shortest path when the pass will actually cross 0° (north). Northbound passes that turn around east of north stay in the primary band (only shown for 450°).
  • Elevation range — 0–90° standard, or 0–180° for over-the-top mounts that can track past zenith by flipping azimuth.
  • Track-start elevation — tracking begins when the satellite rises above this angle (default −3°). Keyhole pre-position uses this as its floor (not below 0°).
  • Park azimuth / elevation — home position.
  • Park rotator after pass — on by default; moves to park when the satellite drops below track-start. Uncheck to leave the beam where it finished.
  • Calibration offsets — optional az/el corrections (degrees) for pass tracking and manual moves. Park uses configured park az/el exactly.

Keyhole avoidance (0–180° elevation only)

On 0–180° rotators, a high pass near zenith can outrun the rotator — the “keyhole” where azimuth swings rapidly while elevation passes through 90°. OscarWatch can analyse such passes and, when beneficial, pre-position the beam flipped (azimuth +180°, at the track-start elevation) before AOS, then track over the top instead of fighting the keyhole.

These options appear only when elevation range is 0–180°. They are hidden for 0–90° rotators.

  • Enable keyhole avoidance — off by default. Sidebar may show Keyhole Avoidance during a flipped pass.
  • Slew rate (°/s) — your rotator’s maximum speed; used to estimate signal-loss windows.
  • Keyhole threshold (°) — minimum pass max-elevation (60–89°) before a pass is treated as keyhole (default 80°).

Pre-position slews azimuth at the track-start elevation, not below 0°. It does not use the station horizon mask.

If planning fails or the feature is off, tracking uses normal az/el commands.

Standby and manual pointing

Standby parks the rotator and pauses CAT — use when browsing the map. Resume restores pass tracking.

While in Standby, the menu bar shows Rotator (if rotator control is enabled). Point the beam manually without resuming tracking — handy for a quick terrestrial contact or between passes.

  • Enter Azimuth and Elevation within your configured limits.
  • Rotate — slew to position; Stop — halt in progress; Park — go to park.
  • Close — dismiss the dialogue; beam stays put until Park or Resume.

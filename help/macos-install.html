Pre-built OscarWatch releases from GitHub are not Apple-notarised (no paid Developer ID). On a Mac, the first launch needs a one-time quarantine clear. Prefer the OscarWatch.app zip; a portable folder archive is still published for operators who already use that layout. These prompts are normally one-time per install.

Which download? Pick the archive that matches your Mac: osx-arm64 for Apple Silicon (M-series), or osx-x64 for Intel. Both shapes are on the Releases page: *.app.zip (recommended) and *.tar.gz (portable folder).

Recommended: OscarWatch.app

  1. Download OscarWatch-version-osx-arm64.app.zip (Apple Silicon) or …-osx-x64.app.zip (Intel).
  2. Open the zip in Finder (double-click, or right-click → Open With → Archive Utility). You should see OscarWatch.app and Remove Quarantine.command.
  3. Drag OscarWatch.app to Applications (or keep it wherever you prefer).
  4. Clear quarantine, either:
    • Double-click Remove Quarantine.command in the extracted folder (if macOS blocks it, right-click → Open once), or
    • In Terminal (adjust the path if needed): 
      xattr -cr /Applications/OscarWatch.app
  5. Open OscarWatch from Applications (or Launchpad). If Finder still blocks it, right-click → Open once.

If you use Settings → Recording, grant microphone access when prompted. Tracking, passes, and radio/rotator control work without recording.

Portable folder (existing method)

Each release also includes OscarWatch-version-osx-arm64.tar.gz (or osx-x64): a folder with the OscarWatch executable, not an .app wrapper.

  1. Download the matching .tar.gz from GitHub Releases.
  2. In Finder, right-click → Open With → Archive Utility. That creates a folder (for example OscarWatch-osx-arm64 contents in Downloads).
  3. For convenience, rename that folder to OscarWatch.
  4. Clear quarantine on the whole folder so nested libraries are cleared too (replace xxxx with your macOS user name and adjust the path if needed): 
    xattr -cr /Users/xxxx/Downloads/OscarWatch
  5. Double-click the OscarWatch executable inside that folder. Alternatively, right-click → Open once if Finder says the file “cannot be opened”.

After install

Settings and logs live under ~/.config/OscarWatch/ (or your XDG config directory). See Quick start for station setup, TLE refresh, and your first pass.

Troubleshooting

  • Still blocked: quit OscarWatch, run xattr -cr again on the .app or folder, then relaunch (right-click → Open if needed).
  • Wrong architecture: an Intel Mac needs osx-x64; Apple Silicon needs osx-arm64.
  • Serial ports: pick /dev/cu.* under Settings → Radio / Rotator; see Radio & rotator.
  • Allow Anyway for a .dylib: uncommon after a recursive quarantine clear. If it still appears, use System Settings → Privacy & Security → Allow Anyway, then relaunch.

See also Problems? → macOS install.
